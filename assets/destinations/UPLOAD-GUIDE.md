# SaahiRides destination image library

Upload destination photos here from a mobile browser. Each destination has its own folder.

## Mobile upload steps
1. Open this repository in Chrome: https://github.com/saahirides/SaahiRides-website
2. Sign in to the GitHub account that has **Write** access to this repository.
3. Open `assets/destinations/`, then open the destination folder.
4. Tap **Add file → Upload files** (on a phone, use Chrome's menu → **Desktop site** if the upload option is hidden).
5. Select photos from your phone. Add them to the destination folder and commit with a clear message. Do not replace an existing filename unless you intentionally want to update that exact image.
6. Use the filename pattern below. The website will use the three numbered lead images as the initial display and place the remaining `gallery-` images in that destination's Explore Gallery once the gallery wiring is deployed.

## Required three lead images per destination
- `01-vehicle-pricing.jpg` — SaahiRides vehicle categories, pickup/drop and prices.
- `02-destination.jpg` — a genuine destination/experience photograph.
- `03-ticket-pricing.jpg` — venue ticket prices, with adult and child rates clearly separated.

## Extra photos
- `gallery-01.jpg`, `gallery-02.jpg`, etc. — additional destination images, shown only inside that destination's Explore Gallery.

## Important
- Keep originals. Add new photos; do not delete or overwrite originals.
- Use JPG, PNG or WebP. Prefer compressed images under 2 MB each for mobile uploads.
- Do not upload customer faces or personal information without consent.
- Do not invent ticket prices. Mark unknown prices as pending until verified.
- Folder upload access is GitHub repository access, not a public anonymous upload form. Never share your GitHub password or access token.
