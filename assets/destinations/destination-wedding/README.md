# Destination Wedding Planner

SaahiRides destination image folder.

Add these three lead images here:
- `01-vehicle-pricing.jpg` — vehicle categories, pickup/drop and prices
- `02-destination.jpg` — destination experience photograph
- `03-ticket-pricing.jpg` — adult and child ticket prices

Add extra images as `gallery-01.jpg`, `gallery-02.jpg`, etc. These belong inside this destination's Explore Gallery, not the three-image main display.

Upload from mobile using the instructions in [the destination image upload guide](../UPLOAD-GUIDE.md).
